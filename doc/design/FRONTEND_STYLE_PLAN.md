# 前端样式开发计划：虹光日夜 · 柔和圆角卡片

版本：v1.2 · 2026-11-05。状态：设计规范与原型，尚未实现 PySide6 应用。

承接 [Windows 应用总计划](WINDOWS_APP_PLAN.md)。用户已选择 A 状态首页＋首次引导，并明确选择“更柔和的圆角卡片风”。本轮按用户提供的三张 Gemini 参考图继续设计：珠光白日间、靛蓝夜间、右侧人物与左侧功能区。保留已选结构，将素材、配色、尺寸和交互统一为可实现规则。

交付索引：[浅色首页设计稿](ui-home-light.png) · [深色首页设计稿](ui-home-dark.png) · [词典设计稿](ui-dictionary-light.png) · [交互样式原型](frontend-style-preview.html) · [设计参数 JSON](assets/frontend-tokens.json)。原型只操作内存中的示例，不读写安装、不测试真实网络、不保存实际词典。颜色、尺寸和页面样例是实现依据；HTML/CSS 只用于审阅，正式应用采用 PySide6 Qt Widgets。

## F1. 视觉方向与取舍

主方向：虹光日夜。浅色提取素材中的珠光白、淡薰衣草紫、冷蓝；深色对应靛蓝夜景与浅紫操作色。首页采用左侧功能、右侧人物的非对称构图；导航有轻微透底，功能卡和输入区用实色，圆角与留白保持亲和。虹彩只出现在小标识和装饰短线，状态颜色仍表达真实含义。

- 首页保留安装信息、词典待应用提示、汉化和代理两张功能卡、最近操作；右侧人物为装饰，不覆盖文字或承载按钮。标题“中文界面，从这里开始。”下面始终能看到当前状态。
- 词典页保留紧凑、可扫描的表格，不把每个词条做成一张大卡片。
- 卡片圆角 16，输入框和按钮圆角 10，提示条圆角 12；每种控件使用固定语义尺寸。
- 默认按系统选择浅色/深色，也可手动选择。浅色为设计基准，两个主题都纳入首版交付。Windows 高对比度模式优先于品牌配色。
- 原生窗口标题栏负责拖动、缩放、最小化、最大化和关闭。设计稿中的标题栏只示意空间；正式首版不自绘窗口框。导航透底只合成同窗口背景，功能区不依赖实时毛玻璃或系统透明材质。
- 装饰阴影只用于少量悬浮弹窗；常规卡片靠间距、底色和细边框分组。Qt 实现不要求逐卡片添加阴影特效。

第二次审视结论：区别于通用仪表盘的重点应是“保存→待应用→已应用”一直看得见，以及汉化、代理两条独立状态链。保留这两个信息特征，删去与任务无关的仪表盘装饰。

## F2. 配色与设计参数

设计参数是统一保存颜色、字号和尺寸的表。`assets/frontend-tokens.json` 是本轮可检查的数据文件，`artwork` 中的素材路径以本设计目录 `doc/design/` 为基准；HTML 内嵌参数与此文件保持一致。实施时映射到 `app/ui/theme/tokens.py` 或等价单一来源，再生成 Qt 调色板和 QSS（Qt 控件样式表），避免各页面各写一套数值。

本项目采用正文文字对比度至少 4.5:1、大字至少 3:1 的验收目标；输入框轮廓、焦点和必要图标目标至少 3:1。数值来源于 W3C 对比度说明，作为本桌面工具的设计验收基准，并非已经获得可访问性认证。[文字对比度参考](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

## F3. 字体、图标、密度与尺寸

所有尺寸均为逻辑像素，即随屏幕缩放的界面单位，不是截图的物理像素。正式 Qt 布局使用设备无关坐标，不手工乘屏幕 DPR。字体采用系统字体回退：Segoe UI Variable → Segoe UI，中文优先 Microsoft YaHei UI → Microsoft YaHei；不要求用户下载字体。Qt 中用 QFont 的字体列表/回退策略，不把 CSS 的 font-family 写法原样搬过去。

| 内容 | 大小 / 字重 | 行高与规则 |
| --- | --- | --- |
| 首页主标题 | 36 / 600；紧凑 30 | 约 1.35 倍；两行，窄屏最低 28 |
| 页面标题 | 26 / 600 | 约 36；可换行，不能压住按钮 |
| 分组标题 | 18 / 600 | 约 26 |
| 卡片标题 | 16 / 600 | 约 24 |
| 正文、表格、按钮 | 14 / 400；按钮 600 | 约 22 |
| 帮助、状态标签 | 12 / 400–600 | 约 18；关键信息不用更小文字 |
| 路径/错误详情 | 13 / 400 | 路径可选择复制；技术详情可用 Consolas 回退 |

Qt 字号如采用 point size，按 96 DPI 基准将设计像素×72/96 转换为点，再交给 Qt 缩放。布局最小高度应结合 `QFontMetrics` 计算，不能仅靠固定高度截断中文。另提供 100%/115%/130% 应用文字大小，改变字号后重算控件最小高度和换行，不二次乘系统缩放。

| 参数 | 默认值 | 规则 |
| --- | --- | --- |
| 间距阶梯 | 4 / 8 / 12 / 16 / 24 / 32 | 文本关联用 4–8，组件用 12–16，分组用 24–32 |
| 页面内边距 | 32；紧凑时 16–24 | 上下左右保持一致 |
| 卡片内边距 / 卡片间距 | 20 / 16 | 大卡可 24，但不随意混用 |
| 常规按钮/单行输入框 | 最小高 40 | 左右内边距 16；按钮宽随中文内容自适应 |
| 小工具按钮 | 最小高 32 | 图标按钮点击区至少 32×32，主操作仍用 40 |
| 导航行 | 最小高 44 | 图标 20、文字 14、左右间距 12 |
| 表头 / 表格行 | 最小高 36 / 44 | 文字放大后可增长；长文在编辑区完整呈现 |
| 图标 | 16、20、24 | 统一线宽约 1.75；采用同一套经许可核对的 SVG |
| 焦点标识 | 2 宽 | 外观留出空间，不因焦点出现而挤动布局 |

正式软件图标来自本地 SVG 资源并随包分发；装饰图标不能替代按钮文字，不依赖 emoji、网络图标 CDN 或某个用户未安装的图标字体。原型中的简易线条图形仅表达位置，不代表最终商标。

## F4. 窗口结构与缩放规则

基准内容区域 1280×820；本轮展示稿画布为 1440×900（含示意标题栏），启动时限制在可用屏幕约 90% 范围内，并恢复上次有效位置。系统标题栏高度由系统决定。舒适使用目标 960×640，但不能设置会超出高 DPI 小屏幕的固定最小窗口；紧凑布局至少处理 720×480 可用内容区域。

| 区域 | 常规布局 | 紧凑布局 |
| --- | --- | --- |
| 左侧导航 | 208 宽，图标＋文字；底部外观设置 | 窗口宽 <900 时 72 宽，保留工具提示和可访问名称 |
| 页面头部 | 标题和说明在左，主操作在右 | 按钮移至标题下方，禁止覆盖标题 |
| 主内容 | 自适应占满剩余宽度，页面左右 32 | 左右 16–24，卡片按可用宽度排列 |
| 概览功能卡 | 概览功能列宽 ≥600 时两列；单列最大 760 | <600 时上下排列 |
| 首页插画 | 窗口 ≥1280：背景右对齐，功能区给人物预留约 340 宽 | <1280：缩成页头插画，功能区恢复全宽；可关闭插画 |
| 词典主区 | 内容区宽 ≥840：表格至少 480，编辑器 320–400，间隔 16 | <840：只显示表格；选中后进入同页编辑视图，提供“返回列表” |
| 操作结果 | 当前页内持续显示，可展开详情 | 纵向滚动；标题和结果不能被底部按钮挡住 |
| 对话框 | 常规宽 520；导入冲突宽 760 | 最大不超可用内容区减 32；正文滚动、按钮区固定 |

滚动归属明确：概览/代理/帮助由主内容区纵向滚动；词典表格和编辑器分别滚动，避免表格外再套一层抢夺滚轮。水平滚动仅允许长表格/技术详情；路径可省略中段但能复制全文。缩窗不丢选中词条、筛选条件或未保存输入。

必须覆盖：1920×1080 在 100%/125%/150%/200%；1366×768 在 100%/125%；不同缩放屏幕间移动；窗口最大化、恢复和重启；应用字体放大 130%。以实际可用逻辑区域驱动布局，不按屏幕物理分辨率写死断点。

## F5. 通用组件及所有必要状态

| 组件 | 默认外观 | 状态与交互要求 |
| --- | --- | --- |
| 主按钮 | accent 底、onAccent 字、圆角 10 | hover/pressed 使用专用色；focus 2 边框；busy 保留宽度并改为“处理中…”；disabled 说明原因 |
| 次按钮 | surface 底、controlBorder 边、text 字 | hover 用 subtle；和主按钮同高；不能与主按钮视觉争夺 |
| 文字按钮 | accent 字 | hover 加底/下划线；点击区至少 32 高；用于查看详情/返回 |
| 危险操作 | surface 底、danger 字和边 | 第一次只打开明确的确认；最终确认可用 danger 底并匹配可读文字 |
| 输入框 | surface 底、controlBorder、圆角 10 | focus accent 边；错误 danger 边＋下方文字；只读不伪装为可编辑 |
| 多行编辑 | 与输入框一致，最小高 120 | 随容器增长；不把 placeholder 当永久字段标签 |
| 导航项 | 透明/微底色，图标＋标签 | 选中使用 accentSoft、accent 字、左侧 3 宽标记；同时显示页面标题 |
| 状态标签 | 圆角 8，左右 8、上下 4 | 图标＋状态文字；颜色只作辅助；不是按钮就不加 hover |
| 提示条 | 语义底色、左侧图标、标题和说明 | 信息可关闭；失败/待应用/部分完成在解决前持续显示 |
| 表格 | 无粗竖线，表头 subtle，细分隔 | hover subtle；选中 accentSoft＋可见当前行标识；焦点与选中区分 |
| 进度区 | 当前阶段＋完成阶段列表 | 有真实总量才显示百分比；否则使用不定进度及阶段名称 |
| 轻提示 | 页面下方短消息 | 仅保存成功等非阻断反馈，约 4 秒；失败不只靠短消息 |
| 对话框 | surface，圆角 16，标题/正文/按钮三区 | 先聚焦安全操作，焦点锁在弹窗；关闭后回到触发按钮 |

按钮顺序遵循 Qt 标准按钮盒的系统布局，不从 HTML 样例硬复制左右习惯。破坏性确认不默认响应 Enter；Esc 等同取消（正在执行且不可安全取消时除外）。信息样式的 tooltip 只补充信息，关键指令始终写在页面上。

表单规则：字段上方标签常驻；必填用文字标注；离开字段或提交时校验，不在中文输入法组词期间反复报错；报错后保留输入，焦点移到第一个错误字段。保存失败保留 dirty 状态。

## F6. 概览页：布局与文案

从上到下：“你的中文工作台”小标题＋“中文界面，从这里开始。”两行主标题 → 安装信息卡 → 待应用提示（有修改才出现）→ 汉化/代理两张功能卡 → 最近操作结果。主标题占位有限，状态卡仍为主要操作区。右侧人物保留面部与主体；功能层不跨进人物安全区。

安装卡：应用名称/检测版本、路径、兼容状态、右侧“选择安装”与“重新检查”。版本未知显示“未识别版本”；只通过结构检查时写“文件结构检查通过”，不能替代“已验证兼容”。路径不要在所有页面重复多行占据空间，可在页面头保持简短的所选安装标识。

汉化卡：标题、状态标签、当前词典修订和应用记录、主操作“预览并应用汉化”；辅助“编辑词典”。已应用时主操作根据词典修订显示“重新应用汉化”，不要关闭重跑入口但需说明原因。卡片不把整个背景做可点击区域。

代理卡：标题、配置状态、说明“配置状态与网络连通性分别判断”；次操作“检查代理启动”。首页只让汉化按钮使用强调填充，代理页的执行修复按钮再成为该页主操作。

最近结果：显示时间、动作、成功/部分完成/失败、下一步；“查看详情”展开当前会话事件。用户点击“启动 Antigravity”后独立报告启动结果，不能覆盖此前汉化结果。

## F7. 词典页：列表、编辑和生效状态

头部：标题“翻译词典”；右侧“添加词条”。下一行搜索框（英文/中文均可）、用途筛选、来源筛选；“导入/导出”放在工具菜单。筛选选择用下拉框，不无限增加横向标签。

常规表格列：原文、译文、来源。用途和分类放在筛选及选中详情；宽屏可显示用途列。原文与译文列可拖拽，推荐最小 180/160；来源 80。整行高至少 44，文本默认单行省略；完整内容在编辑器与可访问文本中提供。排序必须保持稳定 ID，不按当前行号保存。

编辑器顺序：标题/来源标记 → 用途 → 原文 → 译文 → 内置译文对照（覆盖内置时）→ 可读匹配说明 → 保存区域。主要按钮“保存修改”，次要“取消编辑”；“恢复内置”和“禁用此词条”放在更多操作中。普通词条可修改；动态/系统规则显示“规则说明（只读）”，提供示例与版本说明。

需要区分三个状态：

| 状态 | 显示 | 允许动作 |
| --- | --- | --- |
| 未保存输入 | 编辑器标题旁“未保存” | 保存/放弃/继续编辑；切换条目前询问 |
| 已保存未应用 | 页面上方 warning 提示“词典已保存，尚未应用到当前安装” | 预览并应用；继续编辑 |
| 已应用 | success“当前词典已应用”＋目标版本/时间 | 继续编辑、重新应用、查看详情 |

空列表与搜索无结果分开。搜索无结果提供“清除筛选”和“用此原文新增”。输入有改动时关闭窗口、切页、换词条都使用一致的未保存处理；仅在真实 dirty 时弹出。Ctrl+S 保存当前词条，Ctrl+F 聚焦当前页搜索；中文输入法确认按键不误触发页面提交。

导入预览：总条数、新增/覆盖/冲突/无效分别显示；冲突行可选择保留本地或采用导入，底部显示明确汇总。格式无效时显示位置与原因，保持原词典不变。不能仅凭“导入成功”通知掩盖跳过的条目。

## F8. 代理、恢复与首次引导

代理页：系统代理信息卡（开关/类型，敏感地址按需要隐藏）→ 启动器状态 → 快捷方式预览表 → 执行结果。快捷方式表列为名称、位置、计划操作、状态；所有路径支持复制。自定义扫描目录放在“其他位置”折叠区。

主按钮初始“预览修复”；完成预览后“修复 N 个入口”，并显示会新增的启动文件。执行后区分全部完成/部分完成/失败，保留未处理项及下一步。移除代理启动作为次级入口，解释“改回直接启动，保留快捷方式”。配置成功且未检测连接时明确显示“未测试网络连接”，不使用绿色“网络正常”。

恢复与帮助页：恢复英文卡（恢复来源有效性、目标安装、影响说明）→ 会话结果和诊断导出 → 常见问题 → 外观设置。外观设置含跟随系统/浅色/深色、显示插画、文字大小、减少动态效果；无需为外观偏好再增加第五个主导航页。

恢复确认文案：“将恢复当前安装的英文界面；你的自定义词典会保留。请先保存 Antigravity 中的工作。”按钮“返回”和“恢复英文”；缺少有效原版时禁用执行并解释修复官方安装路径。

首次引导采用 3 步短弹窗：选择安装 → 检查与说明 → 进入概览。第一步检测唯一安装时展示并预选；无安装时直接提供浏览；多个安装必须选。引导自身不执行汉化、不要求账号。后续只有实际执行时再显示影响确认，不重复整套教学。

## F9. 状态矩阵与异常文案

| 情况 | 视觉形态 | 文案要点 | 可执行下一步 |
| --- | --- | --- | --- |

## F10. 动效、焦点、键盘与可访问性

- 悬停/颜色切换约 120 ms，弹窗出现最多 160 ms；没有弹跳、闪烁、持续漂浮或循环庆祝动画。
- 减少动态效果设置开启时取消过渡；状态与进度仍显示文字。动画不会延迟执行和按钮可用性。
- 所有按钮、输入框、导航项和表格有键盘焦点；Tab 顺序按视觉阅读顺序，Shift+Tab 反向，表格用箭头移动。
- 导航收起后仍有 accessibleName 和 tooltip；每个输入字段与标签建立关联；错误和最终结果可被读屏获知。
- 焦点与选中样式不只依赖颜色：使用边框/左标记/文字状态。焦点回到触发弹窗的控件，搜索后不随意抢焦点。
- 高对比度模式使用系统 palette 替代品牌色，移除装饰底色；屏幕阅读器支持须在 Qt 实现后用 Windows Narrator 实测，不以网页原型通过代替。

## F11. PySide6 实现路线

| 范围 | 推荐 Qt 组成 | 实现注意 |
| --- | --- | --- |
| 窗口/导航 | QMainWindow、布局、QStackedWidget | 保留系统窗口框；页面状态不因切换而丢失 |
| 卡片/提示 | QFrame＋QLabel＋布局 | 用语义 objectName/property 样式；避免大面积 QWidget 全局选择器污染弹窗 |
| 输入与按钮 | QLineEdit、QPlainTextEdit、QPushButton、QDialogButtonBox | 统一最小尺寸与焦点；正确处理只读、禁用和输入法 |
| 词典列表 | QTableView＋QAbstractTableModel＋QSortFilterProxyModel | 使用稳定 ID；大量行不创建逐格 QWidget；状态标签用 delegate 绘制 |
| 编辑器 | QWidget＋表单布局；宽屏 QSplitter | 窄屏切换为编辑页面而非继续挤压表格 |
| 进度/结果 | QProgressBar＋阶段列表 | 工作线程发 signal，GUI 主线程更新控件 |
| 外观 | QPalette＋集中生成的 QSS | QSS 是 Qt 样式而非浏览器 CSS；不使用 CSS variables、flex/grid、box-shadow 或浏览器 transition |
| 图标与主题 | QIcon/SVG、本地 Qt 资源 | 同语义图标在不同主题使用正确前景色；验证 SVG 插件被打包 |

QSS 按钮至少定义默认、`:hover`、`:pressed`、`:disabled`、`:focus`；导航选中和表单错误用动态属性，并在属性变化后按 Qt 要求刷新样式。预留边框宽度避免状态变化导致控件跳动。表格选中、当前行、悬停与焦点通过 palette/delegate 协调，不靠几条 QSS 假设覆盖全部行为。[Qt 样式参考](https://doc.qt.io/qt-6/stylesheet-reference.html)

Qt 6 提供设备无关像素与高 DPI 支持；实施时验证选定版本的实际行为，不追加 Qt 5 时代的开关或自行按 DPR 放大整个界面。[Qt 高 DPI](https://doc.qt.io/qt-6.8/highdpi.html) Windows 字体建议参考 [Microsoft 字体指南](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/typography)。

建议目录（规划，尚未创建应用代码）：

```text
app/ui/theme/tokens.py         语义颜色、间距、字体、尺寸
app/ui/theme/palette.py        主题/系统高对比度、QPalette
app/ui/theme/stylesheet.py     由参数生成 QSS
app/ui/components/            统一按钮、状态标签、卡片、提示、结果面板
app/ui/pages/                 overview、dictionary、proxy、recovery
app/ui/dialogs/               first_run、confirm_action、import_conflicts
app/ui/models/                界面数据模型/排序筛选（不复制词典业务规则）
app/ui/resources/icons/       本地图标及来源许可
app/ui/resources/artwork/     日间/夜间背景；尺寸与哈希清单
app/ui/components/artwork.py  背景缩放、遮罩、窗口宽度降级与缓存
app/ui/preview/               组件样例与模拟状态，用于开发验收
```

应用外观偏好可以写入现有 settings.json，业务词典继续使用自己的存储。页面只传达用户意图、渲染结果，不直接写 Antigravity 安装目录。

仓库 `assets` 保存用户提供原图的逐字节副本；`manifest.json` 记录尺寸、字节数、SHA-256 和来源。素材本身未重绘、去字或裁切保存。原型以布局规则进行显示裁切；海报只供设计参考，正式运行包只需两张横版图。软件继续暂称 Antigravity 中文助手，图中品牌和模型文案不改变产品定位。

图层由后向前：原始背景 → 左侧向右渐隐的主题遮罩 → 侧栏薄透底 → 实色功能卡和控件 → 状态标签。浅色遮罩 `#F5F4FD`，深色 `#10142C`，左至右遮罩不透明度约 97% / 88% / 12% / 0%，对应横向 0% / 40% / 70% / 84%。导航浅色约 94%、深色约 96% 不透明；表格、输入框、错误详情和弹窗始终 100% 实色。人物附近不放悬浮快捷按钮。

首页宽屏功能列最大 760，人物预留约 340。1280 以下不继续挤窄操作区，改为页头插画；更窄时卡片堆叠。词典/代理/恢复页将插画压到外缘，由实色工作面承载内容；不在每个页面重复一个大人物横幅。关闭插画后取消背景，概览可扩展到 980 宽；所有状态与功能位置规则仍可用。高对比度自动隐藏插画。

Qt 实现：背景部件负责原图等比绘制与遮罩；按资源、目标尺寸、主题和设备缩放缓存合成结果，仅在这些输入变化时重建。卡片和表格继续由普通控件绘制。不为每张卡运行实时模糊，不引入 WebView 作为实际前端。显示失败时回退到主题 canvas 并保留全部功能；资源从随包路径读取，运行时无需下载。透明背景只是同窗口绘制，不表示窗口可透到桌面。
